# M6.5 Advisory Detector 与 Challenge Transfer 补充冻结决策
## Warning-Only Runtime Integration and Out-of-Template Evaluation v1

- 状态：已接受
- 日期：2026-09-29
- 前置：M6.4 PASS（18/18）

## 1. 评估结论

模板 holdout 0 FN 不足以证明迁移。M6.5 同时做两件事：将冻结 detector 以独立、warning-only、非阻断报告接入 Run；建立不参与阈值选择的 out-of-template challenge set。二者都不得改变 M5 gate 决策或 EventLog。

## 2. Advisory Audit

命令：

```bash
python studio.py audit advisory \
  (--book ID | --path PATH) --run RUN_ID \
  --thresholds PATH --evaluated-at ISO [--json]
```

报告必须重新校验 M5 hash chain，绑定 approved prose、hard audit 与 threshold bundle。`evaluated_at` 必须 timezone-aware，且处于 calibrated/expires 闭区间内，以保持可重放和 expiry enforcement。

Findings 固定为 `warning`，报告固定：

```text
advisory_only=true
blocking=false
thresholds_applied=true
```

状态机 state 不变；只允许增加 `advisory_audit_hash`。Audit gate 不依赖 advisory report，hard-failed 规则不变，EventLog bytes 必须不变。

Persona detector 只处理显式 `novel:persona` annotation，并要求 ContextPack psychology facet 中存在同 subject 的 `persona_baseline`。缺少结构化 baseline 或 annotation 时 feature 为 unavailable，不得从自然语言臆测人格漂移。

## 3. Challenge Transfer

Challenge set 不参与 train/calibration/template holdout，冻结为每 detector 12 条（6 positive/6 negative），总计 36：

- 一半 positive 与 v1 feature contract 同构；
- 一半 positive 使用 out-of-template 表达：无 persona annotation、单句内重复子句、未冻结 filler 同义语；
- negatives 使用不同、无命中表达。

预期该设计主动暴露迁移缺口，而不是追求满分。报告必须单列 template holdout 与 challenge confusion，不得合并后宣称整体准确率。

## 4. 诚实声明

- Persona 自然语言漂移仍不被自动识别；
- exact sentence repetition 不能覆盖同义/子句级 trope repeat；
- frozen filler lexicon 不能覆盖所有 padding 表达；
- challenge FN 是后续 corpus/feature 设计输入，不得通过读取 challenge labels 直接调回 v1 threshold；
- threshold 保持 warning，不能提交 authority event。

## 5. 排除与下一步

M6.5 不实现模型 Judge，不升级 hard gate，不执行 3/30 章压测。通过后下一步只能评估 M6.6 三章 smoke：连续生产、advisory evidence、CED、snapshot/中断恢复与无 silent data loss。
