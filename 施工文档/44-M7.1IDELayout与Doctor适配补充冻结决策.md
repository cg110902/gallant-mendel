# M7.1 IDE Layout 与 Doctor 适配补充冻结决策
## Portable Skills and Thin Adapters v1

- 状态：已接受
- 日期：2026-09-30
- 前置：M6 FINAL PASS（35/35）

## 1. 评估结论

M7 的首个动作只建立 canonical skill discovery、四类 IDE 薄适配和确定性 `doctor --agent-layout`。业务协议、权限边界和命令实现继续唯一归属于 `studio.py`/`novel_kernel`；adapter 不能复制或分叉业务逻辑。

## 2. Canonical 与适配布局

Canonical：

```text
.agents/skills/novel-doctor/SKILL.md
.agents/skills/write-beat/SKILL.md
.agents/rules/authority.md
.agents/workflows/novel-{doctor,plan,write,audit,commit,resume}.md
```

Thin adapters：

```text
.claude/CLAUDE.md
.claude/agents/auditor.md
.claude/settings.example.json
.cursor/rules/novel-production.mdc
.cursor/agents/writer.md
.cursor/hooks.example.json
.codex/config.example.toml
```

所有路径必须相对工程根目录，不得冻结 `/home/...` 等机器路径；文件不得用 symlink 绕过 workspace 边界。

## 3. Doctor 契约

```bash
python studio.py doctor --agent-layout --no-api-key [--json]
```

必须检查 Antigravity、Claude Code、Cursor、Codex 四类 layout。每类至少 10 个静态发现/安全检查，包括 canonical 引用、studio delegation、protected roots、thinness、可移植路径和配置可解析性。任一失败返回非零，不自动改写适配文件。

JSON 报告保留通用 `checks[]`，新增 `agent_layout.ok` 与逐平台 totals；未请求 `--agent-layout` 时字段为 null，保持旧 doctor 行为兼容。

## 4. 权限边界

Adapter 只能提供发现、触发、sandbox/approval 示例。Writer/Auditor 不得直接写 EventLog、state.db、compiled authority、snapshot manifest 或 chapters。Hook 失败必须暴露，且无 API Key 时 doctor 和核心确定性路径可运行。

## 5. 诚实边界与后续

本阶段验证静态 layout 和 doctor discovery，不声称四个真实 IDE 产品均已完成端到端运行，也不验证厂商版本、真实 hook 生命周期或 sandbox 强制效果。通过后下一步只能评估 M7.2 四 IDE 十项兼容性矩阵的可执行 surrogate 与证据边界。
