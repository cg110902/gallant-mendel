# M7.3 分支、非破坏回滚与确定性导出补充冻结决策

- 状态：已接受
- 日期：2026-09-30
- 前置：M7.2 PASS

## 决策

M7 剩余确定性核心不等待 IDE live attestation：先补齐显式分支、非破坏回滚与 Markdown/JSON/EPUB 导出，再由用户在 Antigravity 一并验收。

1. `branch create` 只能从既有分支 lineage 中的事件建立新分支。
2. `branch rollback` 的含义固定为“从历史事件创建新分支并记录 marker”，严禁截断、覆盖或倒写 main EventLog。
3. branch marker 是 `branch.created` 权威事件；main head 必须保持不变。
4. export 只读取所选 branch lineage 中具有 `chapter.committed` 证据的章节；章节文件 hash 与提交事件不符时必须失败。
5. Markdown、JSON、EPUB 均由同一冻结章节集合生成。EPUB ZIP 元数据固定，重复导出必须 byte-identical。
6. export 发布到内容寻址的 `exports/export_<hash>/`，已有不同字节不得覆盖。
7. export 不写 EventLog、state、snapshots、compiled 或 chapters。

## 诚实边界

EPUB 是最小 EPUB 3 容器兼容接口，不声称通过所有阅读器排版认证。分支当前证明 fork/query/export 与非破坏 rollback marker，不声称完成 branch merge、冲突解决或分布式协作。
