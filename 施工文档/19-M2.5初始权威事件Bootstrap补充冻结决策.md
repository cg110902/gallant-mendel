# M2.5 初始权威事件 Bootstrap 补充冻结决策
## Initial Authority Bootstrap v1

- 状态：已接受
- 日期：2026-09-29
- 前置：M2.1–M2.4 已通过
- 影响范围：approved compiled generation 到初始 Event Envelope、投影与幂等恢复

## 1. 权威切换边界

M2.5 是 Outline 派生候选首次进入 A 级事件权威的唯一入口。`compiled/` 仍是派生产物；只有成功追加到 `ledger/events.jsonl` 的 Event Envelope 才是权威历史。

Bootstrap 不生成 ContextPack、生产 Agent 或正文。

## 2. Human gate

首次 bootstrap 必须同时满足：

- 当前 Outline manifest `status` 为 `approved` 或 `frozen`；
- `approval.owner` 非空；
- `approval.approved_at` 为带时区 ISO 8601 datetime；
- `compiled/current.json` source package hash 与当前 Outline 完整校验结果一致；
- current generation 通过 M2.4 全文件完整性复核。

未批准返回 human gate `4`，不得创建 ledger/state。`recorded_at` 固定取 `approval.approved_at`，使同一批准 generation 的计划字节确定。

## 3. 确定性事件映射

事件顺序冻结为：

1. 按 object_id 排序的 `object.created`；
2. 角色 location/status/psychology/capability/constraint/arc facet，按 `(object_id, facet_type)` 排序；
3. 角色 initial_state 中未映射字段的 `fact.asserted`，按 `(subject, predicate)` 排序；
4. 物品持有和地点势力的 `relation.asserted`，按 relation_id 排序；
5. 按 obligation ID 排序的 `obligation.created` 审计事件；
6. 一个 `audit.completed` bootstrap marker，记录 compile ID、source package hash、approval owner/time 和计划事件总数。

事件 ID 为 `sha256(compile_id + event kind + stable target + ordinal)` 的前 32 个 hex，格式 `event_<32hex>`。所有 bootstrap 事件 `story_seq = 0`，顺序由 parent chain 表示。actor 固定为 `human / studio.outline_bootstrap`；source run 固定从 compile ID 派生。

每条事件 evidence/source ref 指向 `compiled:<compile_id>/<artifact>#<target>`。Object/Facet/Fact/Relation payload 必须通过既有 core.v3 和投影校验；obligation 在 M2.5 仅作为已冻结但尚未业务投影的审计事件。

## 4. 批量预演与提交

提交前必须在隔离临时 book 中：

- append 完整事件 batch；
- 重建 SQLite；
- 通过 integrity/foreign-key 检查。

预演通过后使用 EventLog `append_many` 一次提交真实权威 batch，再原子重建真实投影。投影环境失败时事件仍是权威，可在重跑时从日志恢复投影；不得回删事件。

## 5. 幂等与冲突

- 空日志：允许首次提交；
- 日志以完整且逐字节相同 bootstrap batch 开头：视为已提交，可安全重建/验证投影并返回 `reused_bootstrap=true`；后续正常事件允许存在；
- 日志只是 bootstrap batch 的部分前缀：返回完整性错误 `6`，禁止猜测续写；
- 非空日志与计划首事件不匹配：返回 human conflict `4`；
- 同一 event ID 但字节不同：返回完整性错误 `6`。

Bootstrap 不允许切换到与既有 bootstrap 不同的 compile ID；未来大纲变更必须走 change/reconcile 事件，而不是重新初始化。

## 6. CLI

```bash
python studio.py outline bootstrap --book book_demo
python studio.py outline bootstrap --book book_demo --json
```

成功报告包含 compile ID、event count、head、projection state hash、reused bootstrap、approval owner/time。失败不得输出 traceback。

## 7. 后续边界

M2.6 才执行完整 M2 总验收与首章 ContextPack 前置能力评估；M2.5 不实现 `outline impact`、生产任务或正文。
