# M2.2 大纲语义索引与引用补充冻结决策
## Outline Semantic Index and Reference Validation v1

- 状态：已接受
- 日期：2026-09-29
- 前置：M2.1 已通过
- 影响范围：ID 收集、别名冲突、显式引用、基础时间窗口与顺序约束

## 1. 阶段边界

M2.2 在 M2.1 只读 package 校验之后增加语义索引，但仍不产生 `compiled/`、事件日志或 SQLite：

1. 收集固定语义文件中的顶层长期对象 ID；
2. 收集 chapter 内的 beat ID；
3. 检查全局 ID 冲突与同类型名称/别名冲突；
4. 解析本阶段冻结的显式引用字段；
5. 检查 story 时间窗口和 timeline `before`/`after` 有向图。

不在 M2.2 实现完整字段 schema、剧情可执行性、义务解决充分性、初始知识、intent ledger、production manifest、初始事件或 compiled 输出。

## 2. 语义文件与声明命名空间

| 文件 | 顶层对象前缀 | 允许集合包装键 |
|---|---|---|
| `04-cast` | `char_` | `characters`, `cast` |
| `05-factions` | `faction_` | `factions` |
| `06-places` | `place_` | `places` |
| `07-items` | `item_` | `items` |
| `08-timeline` | `event_` | `events`, `timeline` |
| `09-threads` | `thread_` | `threads` |
| `10-obligations` | `ob_` | `obligations` |
| `11-arcs` | `arc_` | `arcs` |
| `12-chapter-map` | `ch_` | `chapters`, `chapter_map` |

每份文件允许根为数组、单个带 `id` 的对象、上述包装对象或空对象。非空但无法识别的根拒绝。每条记录必须为对象并有匹配前缀的稳定 `id`。chapter 的 `beats[]` 若存在，每项必须有全局稳定 `beat_` ID。

`02-theme`、`03-world`、`13-style`、`14-platform` 在本阶段不作为长期对象集合扫描，避免把配置中的局部 `id` 错当作权威对象。

## 3. 引用白名单

只解析明确字段，不递归猜测任意字符串：

- Character：`initial_state.location`、`arc_refs`；
- Place：`faction`、`faction_id`、`owner_faction`；
- Item：`current_holder`、`holder`、`owner`；
- Thread：`owner`、`related_characters`、`related_obligations`；
- Obligation：`source_thread`、`character_visibility` 的键、`evidence_requirement.payoff_requires`；
- Arc：`obligations_created`、`obligations_resolved`；
- Chapter：`arc`、`pov`、`location`、`intent.required_events`；
- Timeline：`before`、`after`。

字段存在时必须使用对应前缀且目标已声明。`vol_` 在 v1 package 没有独立声明文件，M2.2 不把 `volume` 当作可解析引用。

## 4. 冲突与诊断

- 所有收集 ID 全局唯一；
- 同一对象类型内，`name`/`canonical_name`/`aliases` 不得指向不同 ID；
- 一个记录内部 aliases 不得重复其主名称；
- 所有诊断按 `code → path → message` 排序，禁止依赖 dict 或文件系统遍历顺序；
- hard failure 使用既有格式/校验退出码 `2`，且不产生任何 authority 或 compiled 文件。

冻结诊断码：

```text
SEMANTIC_ROOT_ERROR
MISSING_ID
INVALID_ID
DUPLICATE_ID
ALIAS_COLLISION
INVALID_REFERENCE
UNKNOWN_REFERENCE
TIME_CONTRADICTION
CIRCULAR_DEPENDENCY
```

## 5. 时间与有向图

- story 时间必须为 `story:<ordered-key>`；
- 同一记录的 `time.start` 不得晚于 `time.end`；
- timeline 的 `before` 表示当前事件指向目标事件；`after` 表示目标事件指向当前事件；
- 约束目标必须是已声明 timeline event；
- 有向图必须无环；
- 不强制章节世界时间随叙事章节单调增长，因为倒叙合法。

## 6. CLI 与输出

`python studio.py outline validate --book book_demo` 依次执行 M2.1 和 M2.2。成功报告新增确定性的 semantic summary；失败报告返回有序 diagnostics。独立 M2.1 布局脚本可继续只验证布局，用于分层定位。
