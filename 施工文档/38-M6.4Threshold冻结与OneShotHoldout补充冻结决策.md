# M6.4 Threshold 冻结与 One-Shot Holdout 补充冻结决策
## Development/Calibration Selection and Sealed Evaluation v1

- 状态：已接受
- 日期：2026-09-29
- 前置：M6.3 PASS（18/18）

## 1. 评估结论

M6.3 已冻结 label-free features 与 train/calibration/holdout。M6.4 可以选择阈值，但必须把候选生成、阈值选择和 holdout 解封分开：train 只生成候选，calibration 只选择并冻结，holdout 只能在 bundle hash 固定后执行一次。M6.4 仍不接入生产 soft audit。

## 2. Detector 与方向

```text
persona_drift   persona_baseline_mismatch       >= threshold
 trope_repeat   repeated_sentence_excess         >= threshold
word_count_cheat filler_character_ratio          >= threshold
```

Boolean feature 以 false=0、true=1 计。候选 threshold 只由 train 的唯一值和相邻值中点生成。Calibration 选择顺序固定为：最大 calibration balanced accuracy、最少 calibration FP、最多 calibration TP、最大 train balanced accuracy、最高 threshold。不得读取 holdout feature-label 对来选择候选。

## 3. Provenance

Threshold bundle 必须绑定 samples/labels/split/features hashes、extractor version、calibrated/expires 时间、owner、候选数量、train 与 calibration confusion、feature distribution、selection hash 和 bundle hash。每个 threshold 均为 warning；M6.4 禁止发布 hard severity 或修改 M5 gate。

分位数采用 nearest-rank：排序后 `ceil(p*n)-1`。空集合拒绝，不插值。

## 4. One-shot Holdout

Holdout evaluator 只接受冻结且 `holdout_used=false` 的 threshold bundle。Receipt 必须绑定 bundle hash、labels hash、24 个冻结 holdout IDs、逐 detector 与总 confusion matrix。相同 receipt 的重试可幂等；同一路径不同 bytes 拒绝覆盖。

“One-shot”是协议和版本控制保证：threshold bundle 与 holdout receipt 一旦发布，任何后续调参必须创建新 corpus/split/version，不能覆盖 v1 后重新宣称同一 holdout 独立。

## 5. 命令

```bash
python studio.py calibrate thresholds \
  --features PATH --labels PATH --split PATH --output PATH \
  --calibrated-at ISO --expires-at ISO --owner ID [--json]

python studio.py calibrate holdout \
  --thresholds PATH --features PATH --labels PATH --split PATH \
  --output PATH [--json]
```

## 6. 声明边界

Holdout PASS 只证明这 90 条结构化/模板化 calibration corpus 上的确定性规则。它不证明自然语言 PersonaDrift 可自动识别，也不修订 M6.2 原始十类 baseline，不启用生产 gate，不证明 3/30 章可靠。

下一步只能评估 M6.5 advisory detector integration：把冻结 detector 作为 descriptive warning 接入 soft report，并用原始 M6.1 gold 与新增 out-of-template challenge set 测量迁移，禁止直接升级 hard gate。
