# M5.4 Semantic/Style Report 与 Rework Gate 补充冻结决策
## Descriptive Soft Audit v1

- 状态：已接受
- 日期：2026-09-29
- 前置：M5.3 PASS（15/15）

## 1. 评估结论

M5.4 增加确定性的 semantic/style 描述报告和人工 rework/approve gate。软报告只陈述可复算指标，不使用未标定阈值，不输出“文学质量合格”结论，不调用模型 Judge。

## 2. Semantic report

从冻结 intent、candidate claims、reconcile 和 hard audit 统计：required change、fulfilled、missing、emergent、claim/evidence coverage、hard/review finding 数。它标记 unresolved items，但不把缺失或涌现自动升级成新的 hard violation。

## 3. Style report

从 approved `prose.md` 确定性统计：Unicode 字符、非空白字符、段落、句子、中文字符、对话字符与比例、隐藏 claim annotation 数。指标是 descriptive，不设置“好坏”阈值，不声称衡量文风或文学质量。

## 4. Rework gate

```text
audit_passed | audit_review | audit_failed
→ soft_audit_ready  （semantic + style 都存在且 hash 绑定）
→ audit_approved    （human approve；audit_failed 禁止 approve）
→ needs_rework      （human rework；所有 hard 状态均可）
```

人工决定绑定 prose、context、extraction、reconcile、hard audit、semantic report 和 style report hashes。decision 记录不可覆盖，actor 必须非空。`audit_approved` 只表示候选可进入提交准备，不代表已发布或已写入权威状态。

## 5. CLI

```bash
python studio.py audit semantic (--book ID | --path PATH) --run RUN_ID [--json]
python studio.py audit style (--book ID | --path PATH) --run RUN_ID [--json]
python studio.py audit gate (--book ID | --path PATH) --run RUN_ID --decision approve|rework --actor ID [--note TEXT] [--json]
```

semantic/style 成功返回 0；gate approve/rework 成功返回 0；hard-failed approve 返回 3；缺失报告或非法状态返回 1；stale/hash 漂移返回 3/6。

## 6. 安全边界与排除

只写 Run 内 `semantic-audit-report.json`、`style-audit-report.json`、`audit-decision.json` 和 status。不得修改正文、候选制品、EventLog、SQLite、compiled 或 chapters。不接模型、不做商业评分、不自动 rewrite。M5.5 才评估 chapter commit transaction 与 authority event 边界。
