# M6.1 Offline Oracle 与 Mutation Corpus 补充冻结决策
## Calibration Foundation v1

- 状态：已接受
- 日期：2026-09-29
- 前置：M5 PASS（15/15）

## 1. 评估结论

M6 不得先写阈值再寻找数据。首个子阶段只建立可复验的离线正确样本、十类 mutation gold corpus、逐 gate confusion matrix 与固定章节窗口 CED 计量。3/30 章执行器、并发与阈值发布留在后续子阶段。

M6.1 不把当前未实现的软检测器伪装成通过：PersonaDrift、TropeRepeat、WordCountCheat 等 gold-positive 样本在实际 detector observation 为 false 时必须计为 FN，并记录 detector limitation。

## 2. Offline Writer Oracle

Offline writer 是确定性 fixture 生成器，不调用模型/API。它输出一个符合 M5 claim annotation 契约的 controlled-correct prose。相同 oracle version 与 seed 必须产生相同 bytes/hash。

它只证明格式与已声明状态变化正确，不证明文学质量。

## 3. Mutation Gold Corpus

必须生成且只生成以下十类：

- KillThenAct
- GhostCharacter
- TimeReversal
- KnowledgeLeak
- PersonaDrift
- HookRemoval
- ForeshadowGhost
- PowerJump
- TropeRepeat
- WordCountCheat

每个样本必须包含稳定 sample/mutator ID、原始/变异 prose 与 hash、结构化 oracle assumptions、expected gate/rule、ground-truth positive label、mutation evidence。Corpus 自身以 canonical JSON hash 封口。

Gate taxonomy 冻结为：`extraction`、`reconcile`、`hard_audit`、`human_review`、`calibrated_style`。这允许区分确定性硬门与尚未标定的软门。

## 4. 指标口径

每个 observation 必须来自 corpus sample ID，并显式提供：actual gate、detected boolean、detector ID/version 和 evidence refs。不能从缺失 observation 推断 TN；缺失 observation 是不完整评估并拒绝出报告。

逐 expected gate 计算：

```text
TP = expected positive and detected
FN = expected positive and not detected
FP = expected negative and detected
TN = expected negative and not detected
precision = TP/(TP+FP), denominator 0 → null
recall = TP/(TP+FN), denominator 0 → null
```

Corpus 包含 paired clean controls，避免只有正样本而无法计 FP/TN。

CED v1 定义为固定章节窗口内的 consistency error 总数除以窗口章节数。窗口不得跨越缺失 chapter index；报告必须保存 window size、start/end、error count 与 density。CED 是一致性错误密度，不是文学质量分。

## 5. 阈值治理

M6.1 只验证 threshold record 元数据契约。任何 threshold 必须有 `calibrated_at`、`sample_size`、`distribution`、`rationale`、`owner`、`expires_at` 和 corpus hash。没有实际 calibration report 的阈值不得进入生产 hard gate。

## 6. 命令

```bash
python studio.py calibrate corpus --output PATH [--json]
python studio.py calibrate evaluate --corpus PATH --observations PATH --output PATH [--window-size N] [--json]
```
