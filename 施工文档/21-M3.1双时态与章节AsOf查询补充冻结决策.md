# M3.1 双时态与章节 As-Of 查询补充冻结决策
## Bitemporal Narrative State Query v1

- 状态：已接受
- 日期：2026-09-29
- 前置：M2 总验收 PASS
- 影响范围：main/branch lineage 的 recorded cutoff、世界有效时间、章节 as-of 只读查询

## 1. 阶段边界

M3.1 只实现双时态状态读取：

- 记录轴：某个 lineage event 之前系统已经接受的权威历史；
- 世界有效轴：某个 `story:<ordered-key>` 时刻成立的 Facet/Fact/Relation；
- 叙事轴：`ch_<number>` 转换为 story sequence cutoff。

本阶段不实现角色知识、读者知识、Future Obligation 状态机、Intent/Reality diff、张力或 ContextPack。

## 2. 权威读取

查询直接读取并验证 append-only EventLog lineage，不把当前 SQLite 反向当作历史权威，也不创建临时数据库。SQLite v1 仍是当前状态派生投影；M3.1 查询器从事件历史确定性折叠版本。

## 3. Recorded cutoff

支持：

```text
--as-of head
--as-of event_<32hex>
--as-of ch_<positive-number>
```

- `head`：目标 branch 完整 lineage；
- event ID：包含该 event 的 lineage 前缀；
- chapter：包含 story_seq 不大于章节号的最长 lineage 前缀。

为防止后写事件泄漏到过去，chapter 查询要求 lineage 的 `story_seq` 单调不下降；违反时返回 hard invariant `3`。Bootstrap 的 `story_seq=0` 因此对所有正章节可见。event cutoff 不要求 story_seq 单调。

未知 event、非法 chapter、空 lineage 明确失败。默认 branch 为 `main`。

## 4. 世界有效时间

`--valid-at` 可省略；省略表示“在 recorded cutoff 下的当前接受状态”。指定时必须是 `story:<ordered-key>`。

时间窗口采用半开区间：

```text
valid_from <= valid_at < valid_to
```

`valid_to: null` 表示无上界；`story:initial` 是最小世界时刻；`unknown` 只在未指定 valid_at 时可作为当前记录返回，不参与点时刻匹配。

## 5. 折叠规则

- Object：create → rename → retire，按 recorded prefix 折叠；默认只返回 active object，可用报告计数识别 retired；
- Facet：按 `(object_id, facet_type)` 保留 recorded prefix 中最后接受的 assertion；`facet.superseded` 清除该 key；然后应用 valid window；
- Fact：assertion 后可 disputed；应用 valid window；
- Relation：assertion 后可 invalidated，后者冻结 `valid_to`；应用 valid window；
- 非业务事件只影响 cutoff/head，不改变四类状态。

查询器必须复用既有 Object/Facet/Fact/Relation payload 校验，不能宽松解释损坏事件。

## 6. 输出

命令：

```bash
python studio.py state query --book book_demo --as-of ch_001
python studio.py state query --book book_demo --as-of event_<id> --valid-at story:0019-04-01T09:00
```

成功 schema：`temporal-state.v1`，包含 branch、cutoff selector/event/index/story_seq、valid_at、objects/facets/facts/relations、retired object count 和 canonical logical state hash。数组按稳定 ID/key 排序，报告不含墙钟时间。

查询严格只读。无效输入为 `1`，hard narrative invariant 为 `3`，EventLog/模型完整性错误为 `6`。
