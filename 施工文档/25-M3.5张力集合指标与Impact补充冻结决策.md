- 状态：已接受

## 1. 边界与原则

M3.5 完成 M3 状态层的最后分析切片：知识集合张力窗口与权威状态依赖 impact。指标只描述可验证集合结构，**不得宣称衡量文学质量、悬念好坏或商业价值**。

不实现 ContextPack、模型调用、生产 Agent 或正文。

## 2. Reader tension 集合指标

命令：

```bash
python studio.py reader tension --book book_demo --holder char_hero --as-of ch_010 --window 5
```

- `--as-of` 必须是 chapter selector；`--window` 为正整数，窗口截断到 ch_001；
- 每章复用 M3.2 knowledge diff，得到 `R-C`、`C-R`、`R∩C`、`T-(R∪C)`；
- 输出每章四集合数量、窗口 totals、末章 snapshot、变化量和 canonical hash；
- holder 必须显式提供，不能从缺少 POV 权威字段的当前模型中猜测；
- chapter lineage 必须满足 M3.1 story sequence 单调不变量；
- 无对应 authority prefix 的窗口早期章节跳过并报告实际 sample 数。

## 3. Impact / blast radius

命令：

```bash
python studio.py impact analyze --book book_demo --object char_hero --as-of head --depth 3
```

在 M3.1 as-of logical state 上建立确定性依赖图：

- Object → 其 Facet、Fact；
- Object/Fact → 以其为端点的 Relation；
- Relation → 另一端 Object/Fact；
- 仅使用结构化 ID 引用，不扫描自然语言，不做向量相似度；
- breadth-first search，depth 为 `1..8`；同一节点保留最短距离；
- 输出 direct nodes、transitive nodes、按类型计数和 canonical hash。

Impact 是“若该节点改变，哪些权威结构应重新检查”的保守结构集合，不自动修改状态，也不声称所有受影响节点都会变化。

## 4. 输出与错误

输出 schema：`reader-tension.v1`、`impact-report.v1`。数组稳定排序，报告不含墙钟时间，查询严格只读。

非法参数退出 `1`；叙事序硬不变量退出 `3`；EventLog/模型完整性错误退出 `6`。
