# 分阶段施工计划与任务清单
## M0–M8 执行版

> 每个阶段都必须有：前置条件、任务、产物、退出条件、禁止越级事项。
>
> “代码能运行”不等于“阶段完成”；阶段完成必须通过验收文档中的证据门禁。

---

## 总览

| 阶段 | 名称 | 目标 | 依赖 |
|---|---|---|---|
| M0 | 工程宪法 | 确定目录、命令、退出码、技术合同 | 无 |
| M1 | 确定性内核 | 事件、对象、时间、投影、快照 | M0 |
| M2 | 大纲编译 | 固定输入规格编译成初始世界 | M1 |
| M3 | 叙事状态 | 义务、知识、读者、意图/实况 | M2 |
| M4 | 生产 Harness | ContextPack、任务图、Agent 产物 | M3 |
| M5 | 审计与提交 | 抽取、平账、硬闸门、提交 | M4 |
| M6 | 标定与压测 | 离线写手、变异测试、阈值 | M5 |
| M7 | IDE 与恢复 | 多工具适配、断点、分支、导出 | M6 |
| M8 | 高级插件 | BoN、模型路由、神经记忆、编辑器 | M7 |

# M0：工程宪法与最小入口

> 本阶段的精确字段、命令、退出码、fixture 和验收证据，以 `09-M0精确施工与验收附录.md` 为准；本节是总计划摘要。
> 实际工程根目录固定为仓库内的 `v2/`，所有命令默认从 `v2/` 执行。

## M0.1 任务

1. 创建项目根目录和 `施工文档/`。
2. 固定 Python 3.11+。
3. 固定退出码 0–7。
4. 固定 `studio.py` 命令命名。
5. 创建 `AGENTS.md` 最小入口。
6. 创建 `tech-stack.yaml`。
7. 创建 `directory-contract.md`。
8. 创建空项目 `workspace/_fixture/`。
9. 写 `studio.py doctor` 的初版。

## M0.2 产物

```text
studio.py
AGENTS.md
tech-stack.yaml
exit-codes.md
directory-contract.md
workspace/_fixture/
scripts/verify_layout.py
```

## M0.3 必须可执行的命令

```bash
python studio.py doctor
python studio.py doctor --no-api-key
python studio.py version
python studio.py help
```

## M0.4 退出条件

- 无第三方依赖可运行。
- 缺目录、缺 Python、缺权限能返回正确退出码。
- `doctor --no-api-key` 成功。
- Agent 读 `AGENTS.md` 后能找到施工文档和命令。

## M0 禁止

- 不建 Web 服务。
- 不接 API。
- 不开始生产正文。
- 不先写复杂 Agent 网络。

# M5：抽取、平账、审计与提交

## M5.1 任务顺序

```text
prose
→ entity/claim extraction
→ evidence binding
→ candidate state delta
→ deterministic reconcile
→ hard invariant check
→ semantic audit
→ style/commerce audit
→ human gate if needed
→ commit
```

> 施工细化（2026-09-29）：M5.1–M5.5 已完成；M5 总回归与单章端到端验收已证明 commit 前候选边界、EventLog-first 提交、原文发布与 chapter as-of 查询闭环。M5 PASS 不代表质量已校准或多章可靠；下一步须先评估 M6。

## M5.2 硬闸门首批

- 未注册实体
- 名称冲突
- 死亡对象行动
- 时间倒置
- 地点不可达
- 角色知识越界
- 资源无来源
- 能力无前置
- 已关闭义务再次出现
- 未来义务无故消失
- 章末状态未能应用
- 禁止事项触发

## M5.3 命令

```bash
python studio.py extract --run run_001
python studio.py reconcile --run run_001
python studio.py audit hard --run run_001
python studio.py audit semantic --run run_001
python studio.py audit style --run run_001
python studio.py commit chapter --run run_001
```

## M5.4 退出条件

- 故意注入每类硬错误都能拦截。
- Auditor 不能绕过 Reconciler 修改状态。
- Reconciler 对同一输入幂等。
- 通过提交后可查询新的双时态状态。
- 失败时保存完整报告和证据。
