# M5 总回归与单章端到端验收补充冻结决策
## M5 Final Acceptance v1

- 状态：已接受
- 日期：2026-09-29
- 前置：M5.1–M5.5 各阶段 PASS

## 1. 评估结论

M5.1–M5.5 已分别证明局部协议，但 M5 退出条件还要求证明各阶段组合后仍保持边界：候选阶段不写权威、提交后新状态能由 EventLog 双时态查询、CLI 产物之间的 hash chain 能完整衔接。因此 M5 总验收不是新增业务能力，而是增加一个独立、真实单章链路和全历史回归证据。

## 2. 单章验收链

验收必须从 approved outline/bootstrap 后执行：

```text
plan/context → writer review approval → extract → reconcile
→ hard audit → semantic/style → human gate → chapter commit
→ chapter as-of query
```

正文包含一个 exact-span claim，提交后必须同时满足：

1. `extract` 到 `audit gate` 期间 EventLog bytes 完全不变；
2. semantic/style 保持 descriptive-only、无阈值质量宣称；
3. commit 发布的 chapter bytes 与 approved prose 完全一致；
4. EventLog 新增稳定提交批次，run 最终为 `published`；
5. `state query --as-of ch_001` 的 cutoff 是 commit head；
6. 新 fact 可由 EventLog 双时态 fold 查询，不依赖 SQLite 作为权威；
7. commit report、status、chapter hash 相互一致。

## 3. 总回归

M5 final verifier 必须执行：

- M5 单章端到端测试；
- 完整单元测试；
- M5.1–M5.5 所有历史 verifier；
- 所有 schema JSON 可解析；
- 所有 evidence index hash 可复验；
- source compilation 与 Git whitespace/hygiene 检查。

任何一项失败均不得宣布 M5 完成。

## 4. 结论边界

M5 PASS 只表示单章确定性抽取、平账、审计、人工批准和可恢复权威提交链已经连通。它不表示：

- 文学质量已经自动判定；
- 阈值已有统计校准；
- 多章或 30 章负载可靠；
- adversarial mutation 的召回率已知；
- 跨资源获得了虚构的 ACID 保证。

下一步只能评估 M6 的 mutation corpus、TP/FP/TN/FN 计量、阈值校准和 smoke/soak 范围；仍须先评估后实施。
