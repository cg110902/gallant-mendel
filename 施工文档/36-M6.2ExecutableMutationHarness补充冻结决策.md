# M6.2 Executable Mutation Harness 补充冻结决策
## Real-Gate Baseline v1

- 状态：已接受
- 日期：2026-09-29
- 前置：M6.1 PASS（17/17）

## 1. 评估结论

M6.1 的 gold labels 与合成 observation 只验证计量器，不能当 detector 实测。M6.2 必须在隔离临时 book 中为 clean/mutated 共 20 个 variant 建立 approved M5 Run，执行对应真实 gate，并保存 detector identity、版本、finding/evidence 与 authority boundary 结果。

## 2. 执行映射

- `extraction`：真实 `CandidateExtractor`，以明确 unregistered-subject 拒绝为检测；
- `reconcile`：真实 `CandidateReconciler`，按 expected classification 检测；
- `hard_audit`：真实 `HardInvariantAuditor`，按 finding rule ID 检测；
- `human_review`：执行 semantic descriptive audit，只认显式 expected rule；不能把 generic review 自动算作 persona detector；
- `calibrated_style`：执行 style descriptive audit；`thresholds_applied=false` 时不得算检测。

KillThenAct 的 oracle fixture 可在 frozen ContextPack 中加入受控 dead object/status，以满足“已注册且已死亡”的前置；这只发生在临时 calibration fixture，不写业务 EventLog。

## 3. 诚实 baseline

预期当前 baseline：七类结构化 detector 可命中；PersonaDrift、TropeRepeat、WordCountCheat 因无已标定 detector 计为 FN。Clean controls 应全部为 TN。任何意外异常、缺失 variant、authority bytes 改变或 detector/gate 不匹配使 harness 失败，不得转写成普通 FN。

## 4. 产物

```text
mutation-observations.v1.json
calibration-report.v1.json
mutation-harness-report.v1.json
```

Harness report 绑定 corpus、observations、calibration report hash，记录 20 个实际运行结果及 authority unchanged 断言。产物必须确定性可重放，不记录临时绝对路径或墙钟时间。

## 5. 命令

```bash
python studio.py calibrate run \
  --corpus PATH --fixture PATH --output-dir PATH \
  [--window-size N] [--json]
```

## 6. 排除与下一步

M6.2 不调整 detector、不启用阈值、不把 FN 隐藏成人工通过，也不宣称多章可靠。通过后下一步先评估 M6.3 soft detector feature extraction 与 calibration split，避免在同一 gold corpus 上调参并报告虚高结果。
