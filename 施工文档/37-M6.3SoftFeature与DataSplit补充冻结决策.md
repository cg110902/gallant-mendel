# M6.3 Soft Feature 与 Data Split 补充冻结决策
## Leakage-Resistant Soft Calibration Dataset v1

- 状态：已接受
- 日期：2026-09-29
- 前置：M6.2 PASS（17/17），baseline TP=7/FP=0/TN=10/FN=3

## 1. 评估结论

当前 PersonaDrift、TropeRepeat、WordCountCheat 各只有一个 positive gold 样本，不能据此选择阈值并再用同一十例报告效果。M6.3 只建立扩展、分层且无跨 split 重复的 soft calibration corpus 与可解释 feature extraction；不选择阈值、不运行 holdout 评分、不修改生产 gate。

## 2. Corpus 与标签隔离

三个 detector family 各 30 个样本：15 positive、15 negative，总计 90。每类固定分层为：

```text
train       6 positive + 6 negative
calibration 5 positive + 5 negative
holdout     4 positive + 4 negative
```

版本化产物拆分为：

- `soft-corpus.samples.v1.json`：sample/prose/context，不含标签；
- `soft-corpus.labels.v1.json`：独立 gold labels；
- `soft-split-manifest.v1.json`：稳定 split IDs 与 samples hash。

Feature extractor 只接受 samples 与 split manifest，不接受 labels。所有 sample/prose hash 必须唯一，任何跨 split ID/hash 重复均拒绝。此隔离是协议防线，不伪装为对仓库读者的密码学保密。

## 3. Feature contract

仅允许可解释、确定性的文本/结构特征：

### PersonaDrift

- frozen persona baseline token；
- candidate persona annotation token；
- exact baseline mismatch boolean；
- annotation count。

该特征依赖显式结构化 persona contract，不推断自然语言人格或文学角色塑造。

### TropeRepeat

- sentence count；
- unique sentence count/ratio；
- maximum normalized sentence frequency；
- repeated sentence excess。

### WordCountCheat

- non-whitespace character count；
- sentence count；
- unique sentence ratio；
- maximum sentence frequency；
- frozen filler-token character ratio。

所有 features 必须带 extractor ID/version、sample/split binding 和 feature hash。Feature 文件不得包含 expected label。

## 4. 数据泄漏防线

- split 在 feature/threshold 开发前冻结；
- holdout 样本不得参与 M6.4 阈值选择；
- train 用于探索，calibration 用于冻结阈值，holdout 只能在阈值冻结后一次性评估；
- 不允许根据当前十例 M6.1 gold 的具体文本构造 exact-match detector；
- 不允许将 sample ID、split 或 label 本身作为 feature；
- 修改 corpus/split/features 任一 bytes 必须改变 hash 并使下游失效。

## 5. 命令

```bash
python studio.py calibrate soft-corpus --output-dir PATH [--json]
python studio.py calibrate features \
  --corpus PATH --split PATH --output PATH [--json]
```

## 6. 排除与下一步

M6.3 不启用阈值，不声称三个 FN 已修复，不执行 holdout，不做 3/30 章压测。通过后下一步只能评估 M6.4 train/calibration threshold selection、冻结 provenance 与 one-shot holdout protocol。
