# M3.4 Intent / Reality 差异分类补充冻结决策
## Intent Reality Diff v1

- 状态：已接受
- 日期：2026-09-29
- 前置：M3.3 PASS

## 1. 范围

M3.4 只实现权威 Intent、正文提交后的 Reality observation 和确定性 diff。新增 core.v3 event type：`intent.registered`、`reality.observed`。不实现张力评分、impact、ContextPack、生产 Agent 或正文。

## 2. Intent authority

Outline bootstrap 必须把 `intent-ledger.json` 每个 chapter 转换成 `intent.registered`，不能在查询时回读可变大纲。Canonical intent：

```json
{"intent":{"scope_id":"ch_001","scope_type":"chapter","required_actions":["event_first_attack"],"required_changes":["char_lin_yun.status=exposed"],"required_reveals":["hook_escape_or_truth"],"required_obligations":[],"forbidden_changes":["new_unregistered_faction"],"source_refs":["compiled:..."]},"evidence":[]}
```

同一 scope 只能注册一次；所有数组去重、稳定解释。

## 3. Reality authority

`reality.observed` 必须在对应 `chapter.committed` 之后，且 `source_event_id` 引用该更早事件：

```json
{"reality":{"scope_id":"ch_001","observed_actions":[],"observed_changes":[],"observed_reveals":[],"observed_obligations":[],"observed_entities":[],"contradictions":[],"approved_missing":{},"approved_extras":{},"source_event_id":"event_...","source_refs":["chapter:ch_001"]},"evidence":[]}
```

每个 scope 只能有一个 active Reality observation。approval map 的值必须引用更早 `audit.completed`；没有审计证据的“批准”非法。

## 4. 确定性分类

- required 且 observed：`intent_fulfilled`
- required 且缺失：`intent_missing`
- required 缺失但在 `approved_missing`：`intent_changed_with_approval`
- observed extra 且在 `approved_extras`：`emergent_valid`
- observed extra 未批准：`emergent_unregistered`
- reality `contradictions`：`contradiction`
- observed change 命中 forbidden：`hard_violation`（优先于 emergent）

分类记录为 `{domain,item,classification,approval_event_id}`，按 domain/item/classification 稳定排序。没有 Reality 时仍返回全部 required 为 `intent_missing`，使未生产与生产缺失可区分于查询失败。

## 5. 查询

```bash
python studio.py reconcile diff --book book_demo --scope ch_001 --as-of head
```

复用 M3.1 recorded/chapter/branch cutoff。成功输出 `intent-reality-diff.v1`，含 intent、reality、分类、七类计数、`has_hard_violation` 和 canonical hash。严格只读。

非法输入退出 `1`；chapter 叙事序不变量退出 `3`；EventLog、引用、模型或 approval 完整性错误退出 `6`。
