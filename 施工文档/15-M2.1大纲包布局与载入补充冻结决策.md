# M2.1 大纲包布局与载入补充冻结决策
## Outline Package Layout and Loader v1

- 状态：已接受
- 日期：2026-09-29
- 影响范围：M2.1 文件集合、manifest、结构化文档载入
- 性质：落实 10 号勘误中的 JSON/YAML 分层，不改变 Outline Package v1 语义

## 1. M2.1 边界

M2.1 只负责：

- Outline 根目录和固定文件集合；
- 文件类型、符号链接和未知根条目拒绝；
- 结构化文档可解析性；
- `00-manifest` 字段与版本校验；
- package 文件 hash 报告。

M2.1 不负责全局 ID 收集、引用解析、循环依赖、时间线、义务、章节语义、初始事件或 compiled 产物。上述工作从 M2.2 开始。

## 2. 等价文件名

作者规范仍以 YAML 表示。零第三方依赖基线允许每个结构化文件使用等价 JSON：

```text
00-manifest.yaml  <=> 00-manifest.json
02-theme.yaml     <=> 02-theme.json
...
14-platform.yaml  <=> 14-platform.json
```

规则：

- 每个固定 stem 必须且只能存在一个 `.json`、`.yaml` 或 `.yml` 版本；
- 同一个 stem 同时出现 JSON/YAML 属于歧义输入，必须拒绝；
- 一个 package 可以混合扩展名，但每份文件都通过对应 loader 独立载入；
- `01-premise.md` 和 `sources/` 的名称固定，不提供扩展名替代。

## 3. StructuredDocumentLoader

核心提供可替换 loader 接口：

```text
StructuredDocumentLoader.load(path) -> JSON-compatible value
```

- JSON loader 使用标准库，始终可用；
- YAML loader 是可选适配器；
- 没有 YAML 依赖时遇到 YAML 输入必须返回明确环境错误语义 `5`；
- 不得自行实现半兼容 YAML parser；
- loader 输出必须能通过 core JSON 规范化，拒绝 NaN、Infinity 和非 JSON 类型。

## 4. 固定根目录集合

必需：

```text
00-manifest.(json|yaml|yml)
01-premise.md
02-theme.(json|yaml|yml)
03-world.(json|yaml|yml)
04-cast.(json|yaml|yml)
05-factions.(json|yaml|yml)
06-places.(json|yaml|yml)
07-items.(json|yaml|yml)
08-timeline.(json|yaml|yml)
09-threads.(json|yaml|yml)
10-obligations.(json|yaml|yml)
11-arcs.(json|yaml|yml)
12-chapter-map.(json|yaml|yml)
13-style.(json|yaml|yml)
14-platform.(json|yaml|yml)
sources/
```

Outline 根目录拒绝未知文件、未知目录、符号链接和非普通文件。`sources/` 允许递归普通文件和目录，但拒绝任意层级符号链接。

## 5. Manifest v1

必填字段保持原规范：

```text
schema_version
book_id
title
language
planned_chapters
canon_policy
```

允许的可选字段：

```text
genre_profile
status
planned_words
chapter_word_range
point_of_view
tense
created_at
last_modified_at
approval
```

未知字段拒绝。规则：

- `schema_version` 必须为 `outline.v1`；
- `book_id` 使用稳定 `book_` ID，并在 CLI `--book` 模式下与目录参数一致；
- `planned_chapters` 为正整数；
- `planned_words` 若存在必须为正整数；
- `chapter_word_range` 为两个正整数且下界不大于上界；
- `canon_policy` 为 `strict | guided | emergent_with_reconcile`；
- `status` 为 `draft | approved | frozen`；
- 日期使用 ISO 8601 日期；
- `approval` 只允许 `owner` 和 `approved_at`；approved/frozen 状态要求非空批准时间。

## 6. 错误与退出码

- 缺文件、未知文件、重复扩展名、路径/布局错误：`1`；
- JSON/YAML 格式、manifest schema 或字段错误：`2`；
- YAML adapter 缺失或环境读取错误：`5`。

校验失败不创建 compiled、events.jsonl、state.db 或其他权威状态。
