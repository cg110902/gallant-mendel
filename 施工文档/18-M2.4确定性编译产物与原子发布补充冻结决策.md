# M2.4 确定性编译产物与原子发布补充冻结决策
## Deterministic Compiled Artifacts and Atomic Publication v1

- 状态：已接受
- 日期：2026-09-29
- 前置：M2.1–M2.3 已通过
- 影响范围：只读大纲编译、内容寻址 generation、原子 current pointer、完整性验证

## 1. 阶段边界

M2.4 把已验证 Outline Package 编译成确定性中间产物，但不追加初始权威事件、不创建 SQLite、不改变作者输入 manifest、不生成 ContextPack 或正文。

`outline compile` 必须先完整运行 M2.1–M2.3；任何 hard failure 都不得发布新 current generation。

## 2. 物理布局

为避免原规范把多个文件直接覆盖到 `compiled/` 时暴露部分新旧混合状态，物理布局冻结为：

```text
compiled/
├── current.json
└── generations/
    └── <64-hex-compile-id>/
        ├── objects.json
        ├── initial-state.json
        ├── obligations.json
        ├── timeline.json
        ├── intent-ledger.json
        ├── production-manifest.yaml
        ├── compile-report.md
        └── artifact-index.json
```

消费者只能先读取 `current.json`，再读取其 generation。禁止扫描目录猜测“最新”。旧 generation 保留为可审计的派生产物；它们不是事件权威。

## 3. 内容寻址

所有 JSON 使用 core canonical JSON bytes，无尾换行。Markdown 使用 UTF-8、LF 和固定末尾换行。`production-manifest.yaml` 使用 JSON-compatible YAML 1.2 表示（canonical JSON 本身是合法 YAML 1.2），从而保持零依赖与字节确定性。

`compile_id` 是以下 preimage 的 SHA-256：

```text
schema_version
compiler_version
book_id
source_package_hash
各逻辑产物 path + byte hash
```

production manifest 和 artifact index 可包含 compile_id；它们不参与该 preimage，避免循环 hash。artifact index 记录 generation 内所有七个逻辑产物的字节数和 SHA-256。

## 4. 原子发布

1. 在 `compiled/` 下创建不可见临时 generation；
2. 写入、flush、fsync 并逐文件复核 hash；
3. 以单次 rename 安装到内容寻址 generation 路径；
4. 最后使用 M1 原子写协议替换 `current.json`；
5. current pointer 成功替换才算发布成功。

若 pointer 之前失败，新建 generation 必须清理；旧 current 字节保持不变。相同输入重复编译复用并复核同一 generation，结果必须幂等。已有 generation 任一文件篡改返回完整性错误 `6`，不得覆盖证据。

`compiled/`、`generations/`、generation 和 current 均拒绝符号链接。

## 5. 逻辑产物

- `objects.json`：按 object_id 排序的 Character/Faction/Place/Item/Thread/Arc/Chapter/Beat 编译记录；
- `initial-state.json`：角色 initial_state、物品 holder、地点 faction 的非权威初始候选；
- `obligations.json`：按 ID 排序的未来义务；
- `timeline.json`：timeline event 与 chapter time，按稳定键排序；
- `intent-ledger.json`：按 chapter ID 排序的 chapter intent；
- `production-manifest.yaml`：book、source hash、compile ID、compiler schema 和 artifact index 关联；
- `compile-report.md`：确定性计数、hash 和 PASS 结论，不含墙钟时间；
- `artifact-index.json`：上述七项的 path/hash/bytes。

## 6. CLI 与错误

```bash
python studio.py outline compile --book book_demo
python studio.py outline compile --book book_demo --json
```

- 输入/路径错误：`1`；
- schema/domain 错误：`2`；
- 环境与权限错误：`5`；
- 已发布 generation 完整性错误：`6`。

成功 JSON 报告至少包含 compile_id、source_package_hash、generation path、artifact index hash、artifact count、reused_generation 和 previous_compile_id。

## 7. 后续边界

M2.5 才评估从 compiled generation 生成初始 Event Envelope、投影和最终 M2 总验收。M2.4 的 initial-state 只是派生候选，不是权威状态。
