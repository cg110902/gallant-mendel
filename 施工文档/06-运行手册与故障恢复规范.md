# 运行手册与故障恢复规范
## 日常生产、断点、回滚、分支与事故处理

---

## 1. 日常生产原则

任何一次小说生产都从生产清单开始，不从聊天窗口开始。

```text
read manifest
→ inspect branch head
→ create task
→ build context
→ run Agent
→ extract
→ reconcile
→ audit
→ human gate if needed
→ snapshot
→ commit
```

---

## 2. 初始化一本书

```bash
python studio.py doctor --no-api-key
python studio.py init book --book book_demo --path workspace/book_demo
python studio.py outline validate --book book_demo
python studio.py outline compile --book book_demo
python studio.py snapshot create --book book_demo --label initial-compile
```

初始化后必须存在：

```text
workspace/book_demo/
├── outline/
├── state/
├── ledger/
├── production/
├── chapters/
├── runs/
├── audits/
├── snapshots/
├── branches/
└── exports/
```

---

## 3. 生产一章

### 3.1 规划

```bash
python studio.py plan chapter --book book_demo --chapter ch_001
python studio.py plan inspect --book book_demo --chapter ch_001
```

确认：

- 章节目的
- POV
- 时间和地点
- 需要履约/触达的义务
- 禁止事项
- beat DAG
- 风险等级

### 3.2 构建上下文

```bash
python studio.py context build \
  --book book_demo \
  --chapter ch_001 \
  --beat beat_001_01
```

ContextPack 必须写入：

```text
runs/<run_id>/context-pack.yaml
```

### 3.3 调用 IDE Agent

Agent 执行 `write-beat` Skill，只能输出：

```text
runs/<run_id>/prose.md
runs/<run_id>/writer-notes.md
```

如果 Agent 直接修改权威状态，立即停止本 Run。

### 3.4 抽取和平账

```bash
python studio.py extract --run run_001
python studio.py reconcile --run run_001
```

### 3.5 审计

```bash
python studio.py audit hard --run run_001
python studio.py audit semantic --run run_001
python studio.py audit reader --run run_001
python studio.py audit style --run run_001
```

### 3.6 提交

```bash
python studio.py commit chapter --run run_001
python studio.py snapshot create --book book_demo --label ch_001-committed
```

## 4. 人工断点

以下情况必须停下，不得自动提交：

- P0/P1 大纲变更
- 核心角色死亡、复活、身份变化
- 核心世界规则变化
- 未来义务提前关闭
- 关键事实存在两个互斥版本
- Judge 无法判断且硬规则无法解决
- patch 后质量变差
- 预算/并发保护触发
- 状态投影重放不一致

人工断点文件：

```text
workspace/<book>/production/human-gates/<gate_id>.yaml
```

必须包含：

- 问题
- 证据
- 候选选择
- 影响范围
- 需要谁批准
- 批准后执行什么命令

## 5. 中断与恢复

### 5.1 Agent 中断

```bash
python studio.py run status --run run_001
python studio.py run resume --run run_001
```

恢复顺序：

1. 读取 Run 状态。
2. 校验 context-pack hash。
3. 检查已有 ArtifactBundle。
4. 检查是否已产生候选状态。
5. 若未提交，继续当前阶段；若状态不明，进入 quarantine。

### 5.2 进程崩溃

```bash
python studio.py doctor --run run_001
python studio.py state verify --book book_demo
python studio.py run recover --run run_001
```

不得直接再次执行 commit。必须先判断上一次是否已经追加事件。

### 5.3 SQLite 损坏

```bash
python studio.py state verify --book book_demo
python studio.py state rebuild --book book_demo
```

SQLite 是派生投影，优先从事件重建，不手工修数据库。

### 5.4 事件日志异常

```bash
python studio.py ledger verify --book book_demo
python studio.py ledger quarantine --event event_00127
python studio.py branch create --book book_demo --from event_00126 --name repair-001
```

原始日志保留；修复在分支进行。

## 6. 回滚与重产

### 6.1 非破坏回滚

```bash
python studio.py branch create \
  --book book_demo \
  --from snapshot_001 \
  --name rewrite-ch-147
```

回滚不是删除后文，而是：

- 创建新分支
- 重放祖先事件
- 在新分支重产
- 对比新旧版本
- 通过人工/自动门禁后再合并

### 6.2 章节重产

```bash
python studio.py rerun chapter \
  --book book_demo \
  --chapter ch_147 \
  --reason patch-regression \
  --from snapshot_147_pre
```

必须保留：

- 原正文
- 原 Run
- 原审计
- 重产原因
- 新旧差异
- 选择结果

## 7. 事故分类与处理

| 事故 | 首要动作 | 禁止动作 |
|---|---|---|
| 写手写错事实 | 保留 Run，生成审计报告 | 直接改 state.db |
| 抽取器漏事实 | 标记 extractor miss，补测试 | 只手工补当前章节 |
| 审计器误报 | 保留样本，进入 calibration | 直接放宽全局阈值 |
| 审计器漏报 | 生成 mutation case | 只修当前 prompt |
| 补丁越修越差 | 拒绝最新补丁，比较版本 | 无条件接受最新版本 |
| SQLite 损坏 | 事件重建 | 手改数据库 |
| 事件损坏 | quarantine + 分支修复 | 删除坏事件 |
| Context 超预算 | 缩小 pack/隔离子任务 | 继续倾倒全文 |
| Agent 提前结束 | 读取 production manifest | 以“完成”文字为准 |
| 多 Agent 互相矛盾 | 回到权威状态和契约 | 让模型投票替代事实 |

## 8. 每日/每章/每卷维护

### 每次运行

- run manifest
- input/output hash
- 退出码
- 产物索引
- 失败原因

### 每章

- 状态重放检查
- 义务更新
- 角色/读者知识更新
- 章节 snapshot
- hard audit
- chapter metrics

### 每 10 章

- 局部时间线审计
- 实体碰撞检查
- 多线进度检查
- 重复和信息熵统计

### 每 30 章

- 固定窗口 CED
- 全局通读审计
- 中部/高熵风险抽样
- 阈值漂移检查
- 生产速度和失败率

### 每卷

- rollup
- reconcile
- export
- 卷级 snapshot
- 义务期权和商业指标复盘
- 人工确认下一卷生产方向

## 9. 发布与导出

发布前：

```bash
python studio.py check --book book_demo --scope chapter --chapter ch_147
python studio.py check --book book_demo --scope volume --volume vol_03
python studio.py export --book book_demo --format markdown
```

导出只读已提交章节，不读取候选 Run。

导出清单必须记录：

- branch
- event head
- chapter range
- state hash
- export hash
- audit status
- unresolved warnings

## 10. 运行手册验收

必须演练：

1. 生产中断后恢复。
2. Agent 越权写入被拒绝。
3. SQLite 删除后重建。
4. 章节回滚并在分支重产。
5. 事件日志故意损坏后隔离。
6. 审计失败后重新生成候选。
7. 人工 Gate 暂停和批准。
8. 无 API Key 模式下完成所有确定性命令。
