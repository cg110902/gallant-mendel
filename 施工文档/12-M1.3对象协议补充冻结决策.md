# M1.3 对象协议补充冻结决策
## Object / Facet / Relation / Fact / Evidence v1

- 状态：已接受
- 日期：2026-09-29
- 影响范围：M1.3 数据模型验证与后续 SQLite 投影
- 性质：对 core.v3 未枚举字段的向前兼容补充，不修改 Event Envelope、权威层级或退出码

## 1. 背景

core.v3 已冻结 Object、Facet、Relation 的原则和示例，但 Fact、Evidence 以及多数首批 Facet payload 尚未精确枚举。直接允许任意字典会违反 ADR-0003；各实现自行猜字段又会导致投影分叉。因此在 M1.3 施工前补充首个版本化、零第三方依赖的验证合同。

## 2. 通用规则

- 机器交换格式为 UTF-8 JSON。
- 每种记录拒绝未知顶层字段。
- ID、predicate、状态和枚举值使用稳定 ASCII。
- 用户可见名称、摘要和原文摘录允许 Unicode。
- 时间字段使用 `story:<有序键>` 或显式 `unknown`；开放结束时间使用 `null`。
- `recorded_event` / `created_event` 使用 core.v3 event ID。
- Relation 和 Fact 必须包含至少一条 evidence ref。
- JSON 数值不得包含 NaN 或 Infinity。
- validators 返回与调用方可变容器脱离的 JSON 值。

## 3. Object v1

固定字段：

```text
object_id
type
canonical_name
aliases
status
created_event
supersedes
```

- `status`：`active | retired | superseded`
- `supersedes`：`null` 或另一个稳定 object ID
- Object 表示稳定身份和生命周期；易变状态进入 Facet，不增加任意顶层字段。

## 4. Facet v1

固定外壳：

```text
object_id
facet_type
facet_version
payload
valid_from
valid_to
source_refs
recorded_event
```

首批类型和 v1 payload：

| facet_type | 必填 payload | 可选 payload |
|---|---|---|
| identity | `identity_kind` | `legal_name`, `pronouns` |
| appearance | `description` | `markers` |
| psychology | `current_motive`, `want`, `fear` | `fear_threshold`, `cognitive_bias` |
| capability | `capabilities` | `limitations` |
| voice | `style_markers` | `forbidden_patterns` |
| knowledge | `fact_ids` | `uncertain_fact_ids` |
| resource | `resources` | `unit` |
| location | `place_id` | `arrival_story_seq` |
| relationship | `relation_ids` | 无 |
| status | `state` | `detail` |
| arc | `stage` | `goal`, `progress` |
| style | `directives` | `avoid` |
| constraint | `rules` | `severity` |

每个 payload 拒绝未知字段。新增字段或版本必须注册新 schema，不得静默放宽 v1。

## 5. Relation v1

固定字段：

```text
relation_id
subject_id
predicate
object_id
valid_from
valid_to
recorded_event
confidence
evidence_refs
```

首批 predicate：

```text
belongs_to
knows
owes
located_at
opposes
possesses
affects
```

`confidence`：`confirmed | probable | disputed | candidate`。

## 6. Fact v1

固定字段：

```text
fact_id
subject_id
predicate
value
valid_from
valid_to
recorded_event
confidence
status
evidence_refs
```

- `value` 可以是任意合法 JSON 值，但不能是 NaN/Infinity。
- `status`：`asserted | disputed | superseded`。
- predicate 必须是稳定 ASCII 标识，不接受自然语言裸句。

## 7. Evidence v1

固定字段：

```text
evidence_id
source_type
source_ref
locator
content_hash
excerpt
recorded_event
```

- `source_type`：`outline | chapter | run | human | event`。
- `locator` 固定字段为 `start`、`end`、`section`；至少一个存在。
- `start/end` 是非负整数且 `end >= start`。
- `content_hash` 使用 `sha256:<64位小写十六进制>`。
- `excerpt` 为 Unicode 字符串或 `null`。

## 8. 引用完整性

M1.3 提供内存级 bundle 校验：

- ID 在各自集合内唯一；
- Facet 的 object 必须存在；
- Relation 两端必须指向已知 Object 或 Fact；
- Fact subject 必须指向已知 Object；
- `evidence_refs` 中以 `evidence_` 开头的引用必须存在；
- `recorded_event` 是否实际存在由 M1.4 投影/重放阶段结合事件日志验证。

## 9. 兼容性

本决策新增精确定义，不改变既有 Event Envelope。后续若需要新的 Facet 字段：

1. 增加新的 `facet_version`；
2. 添加 JSON Schema 和迁移策略；
3. 保留 v1 读取能力；
4. 不得通过关闭未知字段检查来兼容。
