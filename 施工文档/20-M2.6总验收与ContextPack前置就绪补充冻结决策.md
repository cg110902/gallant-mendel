## 1. M2 完成条件

M2 最终 PASS 必须同时满足：

1. 完整样例通过 layout、manifest、semantic、domain 校验；
2. compiled generation 内容寻址、artifact index 与 current pointer 完整；
3. approved generation 可确定性生成初始权威事件和 SQLite 投影；
4. 重复执行不改变 compile ID、事件字节或逻辑 state hash；
5. 至少 12 类故意错误被确定性拦截；
6. M2.1–M2.5 证据索引全部 hash 匹配；
7. 第一章 ContextPack 的确定性输入已齐备；
8. 不存在生产 Agent、production task 或正文产物。

## 2. ContextPack 前置就绪检查

新增只读命令：

```bash
python studio.py outline readiness --book book_demo
```

它不是 ContextPack 生成器。它只验证 current generation、authority log、projection 和第一章计划之间的闭合关系：

- current generation 完整，source hash 与当前 approved Outline 一致；
- authority log 已完成同一 compile ID 的 bootstrap；
- SQLite 是 main lineage 的有效投影；
- 按 chapter ID 排序的第一章同时存在于 objects、timeline 和 intent ledger；
- chapter 的 POV、location、arc 和 required events 均存在于 compiled objects/timeline；
- POV 与 location 存在于投影对象；
- POV 至少有 location、status 和 capability 当前 facet；
- compiled obligations 可读取并计数；
- readiness 不写任何文件。

缺失任一前置条件返回 hard invariant `3`。输入/完整性/投影错误继续使用既有 `1/6` 语义。

## 3. 确定性报告

成功报告 schema 为 `outline.context-readiness.v1`，包含：

```text
book_id
compile_id
chapter_id
pov_id
location_id
arc_id
required_event_count
obligation_count
authority_event_count
authority_head
projection_state_hash
ready
```

报告不包含墙钟时间。
